# SSH

This directory contains Bash scripts and configuration files for learning about SSH (Secure Shell).

## Files
* `0-use_a_private_key`: Bash script that uses ssh to connect to a server using a specific private key.
* `1-create_ssh_key_pair`: Bash script that creates an RSA key pair.
* `2-ssh_config`: SSH client configuration to refuse passwords and use a specific private key.
